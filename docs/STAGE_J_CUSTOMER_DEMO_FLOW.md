# Stage J — customer demo path

The public Streamlit application now includes a device-level flexibility page
alongside the existing site workspace and forecast-led joint-resource optimizer.

Suggested judge/customer journey:
1. Open the public demo and identify the synthetic-data disclosure.
2. Review critical, semi-flexible and fully-flexible equipment schedules.
3. Inspect operating windows, energy requirements, hourly power and remaining
   task capacity.
4. Follow the device task schedule into the shared PV/wind/grid energy balance.
5. Review grid import, modeled energy cost, critical unmet energy and flexible
   load shedding.
6. Export the hourly CSV audit.

The new page uses a fixed illustrative scenario so every visitor sees a
reproducible path without uploading private site data. It is not a customer
case study and its displayed cost is not measured savings. For an actual site,
replace the synthetic tariff, generation, base load, residual task capacity and
device constraints with authorized, validated inputs.
